# BREAKOWT: Seven Days to Steak

A first-person stealth, puzzle and (eventually) combat comedy. You are Cow #47. On Monday you find out
you're scheduled for "processing" on Sunday. You have one week, a handful of very clever friends, and a
farmer who trips over his own boots, to get out of Happy Acres Family Farm.

Everything in the game (the farm, the cows, every moo, every note of music) is generated by code the first
time you run it. There are no asset downloads.

## What you need

- **Windows 11** is where it's made and tested, including on a Windows-on-ARM laptop. Windows 10 should be
  fine. The automated tests also run on Linux. macOS hasn't been tried.
- **Python 3.12 or newer** (tested on 3.13). Get it from [python.org](https://www.python.org/downloads/) or
  the Microsoft Store. On python.org's installer, tick **"Add python.exe to PATH"**.
- About 100 MB of disk space for the generated sounds and textures, and a mouse.

## Download

The repository is private, so you need to have been given access on GitHub. Then either:

- **With git:**
  ```
  git clone https://github.com/CircusPigeon/cow_game.git
  cd cow_game
  ```
- **Without git:** on the [repository page](https://github.com/CircusPigeon/cow_game), click the green
  **Code** button, then **Download ZIP**, unzip it, and open a terminal in the unzipped folder.
  (In File Explorer: open the folder, click the address bar, type `cmd` and press Enter.)

## Install

Once, from inside the game folder:

```
python -m pip install -r requirements.txt
```

That installs [Ursina](https://www.ursinaengine.org/) (the 3D engine, which brings Panda3D with it), numpy,
scipy and Pillow. If `python` isn't found on Windows, try `py` instead; on macOS or Linux, `python3`.

## Play

```
python main.py
```

The game opens fullscreen. For a window instead:

```
python main.py --windowed
```

**The first launch takes a couple of minutes.** The game synthesizes all its sounds and paints its
textures, with a progress bar. It also checks once what your graphics card can handle, and a tiny window
may flash for a second while it does. After that it starts in a few seconds.

On the title screen pick **New game**. **Continue** appears once you've made some progress, and
**Chapter select** jumps straight to any day of the week. Esc pauses (settings, Moo-dals, restart from the
last checkpoint, quit). Press **H** any time you're stuck for a hint.

## Controls

| Key | Does |
|---|---|
| W A S D / arrow keys | walk |
| Mouse | look |
| Shift | gallop (uses stamina) |
| C or hold Ctrl | sneak |
| Space | hop (pathetically) |
| E | interact / talk |
| Left click | headbutt |
| Right click | back-kick (hits what's behind you) |
| R | throw a rock or the selected throwable |
| Q | use the selected item |
| M | moo |
| 1-9, 0 / scroll wheel | pick an item (press its number again to put it away) |
| Tab or J | journal, inventory and map |
| H | hint |
| Esc | pause |
| F11 | fullscreen on/off |
| F12 | screenshot |

In the tractor: W/S throttle, A/D steer.

## Good to know

- **It saves by itself** at every checkpoint. **Continue** picks up from the last one.
- **Chuck can only catch you where a cow shouldn't be.** The pasture is safe. Sneak, stay out of his
  line of sight, sneak into tall grass to hide, and throw rocks to make him look the other way. When
  he's asleep, only sneaking is quiet enough: walk past his bed and he'll get up.
- **Every item does something.** Its description in the journal (Tab) says what. Keys work on
  their own; anything on the hotbar is used with Q or thrown with R.
- **Moo-dals** are the game's achievements, for fooling around as much as for escaping. See them from the
  pause menu or the title screen. They carry over between playthroughs, and each one pays out **Golden
  Clovers**, the only currency Mooriarty (behind the hay bales in the pasture) accepts.
- **Settings** (on the title screen or pause menu): volumes, mouse sensitivity, invert Y, fullscreen, and
  **Graphics** Low / Medium / High. On a slower laptop, pick Low.

## Where your data lives

Saves, settings, Moo-dals, screenshots and the generated sounds and textures all live outside the game
folder, in **Documents\My Games\BREAKOWT** (on Linux or macOS without a Documents folder:
`~/.breakowt`).

- To replay the story, just pick **New game**. To wipe everything, including settings and Moo-dals, delete
  `saves` in there.
- To regenerate the sounds and textures, delete `generated`.
- To re-run the graphics check, delete `gpu.json`.

## Troubleshooting

- **`No module named 'ursina'`:** the install step used a different Python from the one running the game.
  Run both with the same command (`python -m pip ...` and `python main.py`).
- **Ursina won't install:** check `python --version`. It needs 3.12 or newer.
- **Black screen, or the game closes right away:** delete `gpu.json` (see above) so the graphics check
  runs again, and try `python main.py --windowed`. Updating your graphics driver can also help.
- **Choppy:** Settings, then Graphics, then Low.
- **The mouse doesn't turn the camera:** click inside the game window once so it has focus.
